# Network Traffic Classification

## Project Description

Network Traffic Classification is a Machine Learning project
that classifies network traffic into different categories.

## Traffic Categories

- Web Browsing
- Video Streaming
- Online Gaming
- File Transfer
- Chat

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Random Forest

## Machine Learning Process

1. Load Dataset
2. Data Preprocessing
3. Train-Test Split
4. Model Training
5. Prediction
6. Accuracy Evaluation
7. Confusion Matrix

## How to Run

Install libraries:

pip install -r requirements.txt

Run the project:

python network_traffic.py
